Recommended Monthly Workflow

  1. Create/select the month.
  2. Upload the AP invoice/payment report. This drives outflow categorization.
  3. Upload cashbook exports. Cashbook debits drive receipts; cashbook credits are a bank-side validation/control.
  4. Process and save the month. The app stores processed records under data/months/YYYY-MM and commits them.
  5. Use Exceptions Mapping to add or edit rules. Rule changes save to data/mappings/mapping_rules.csv and commit to Git.
  6. Reapply saved rules to refresh the month after mapping changes.

Why GitHub Instead Of A Database?

For your current need, CSV/JSON files in GitHub give you version history, reviewable changes, and a simple audit trail. If you later need record locking, approvals, or many simultaneous users editing at once, then move to a database.
