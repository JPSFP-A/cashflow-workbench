How To Use This HTML Version

  1. Upload the AP invoice/payment report. This drives outflow categorization.
  2. Upload cashbook files. Cashbook debits are receipt-side; cashbook credits are validation/control.
  3. Optionally upload mapping rules CSV exported from this app or from the Git-backed app.
  4. Click Process In Browser.
  5. Use Map Exceptions to add rules. Each new rule reapplies immediately in this session.
  6. Export mapping rules and records before closing the browser.

Important Limitation

This standalone file has no backend. It cannot permanently save files to GitHub or maintain multi-user history by itself. For multi-user persistence, use the Git-backed local/server app.
